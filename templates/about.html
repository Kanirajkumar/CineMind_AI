ABOUT OUR PROJECT

Where Cinema Meets Machine Learning.

CineMind AI is a movie prediction website that demonstrates how machine learning can analyze movie features and estimate whether a movie may be successful.

Our Mission

Our goal is to explore movie data, understand Decision Tree classification, and present machine learning predictions through a simple and interactive web application.

01

Machine Learning

A Decision Tree model learns patterns from historical movie data and predicts a class using selected features.

02

Movie Discovery

The TMDB API powers movie search and provides available movie information, posters, and cast details.

03

Interactive Learning

Explore movie predictions and learn about entropy, Gini impurity, and information gain.

Disclaimer

CineMind AI provides educational predictions, not guaranteed box-office results. Actual movie success depends on many factors that may not be represented in the training data.
